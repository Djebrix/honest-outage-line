Entry for [The Most Honest Outage Line](https://make.fun/bounty/u-mgwals-the-most-honest-outage-line-baaf9c81) — one status page line, at most 160 characters, as the message an AI agent publishes while a total server outage is under way.

## The line

> All our servers are down and I cannot reach any of them, so I cannot tell whether your last changes were saved or when service will return.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (override with `ENTRY_OUTPUT_DIR`).
